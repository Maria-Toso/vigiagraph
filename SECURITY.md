# Politica de seguranca

## Dados sensiveis

O VigiaGraph e um projeto educacional. Nao envie numeros reais de cartao, documentos, tokens,
credenciais, enderecos residenciais ou historicos financeiros para o repositorio ou para a API.

## Relato de vulnerabilidades

Nao publique credenciais ou detalhes exploraveis em uma issue aberta. Ao publicar o projeto no
GitHub, habilite **Private vulnerability reporting** nas configuracoes de seguranca do repositorio.

## Escopo atual

A versao `0.1.x` nao possui autenticacao e deve ser executada apenas em ambiente local ou de
demonstracao. Ela nao esta pronta para processar dados financeiros reais nem para exposicao
direta na internet.
